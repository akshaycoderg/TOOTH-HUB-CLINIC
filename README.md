# The Tooth Hub Dental Clinic

A responsive sample website concept for The Tooth Hub Dental Clinic in Basavanagudi, Bengaluru.

## Live website

[Visit The Tooth Hub Dental Clinic](https://tooth-hub-clinic.vercel.app)

## Project

This is a static website built with HTML, CSS, and JavaScript. Keep the project files together in the repository root:

- `index.html` - page structure and metadata
- `styles.css` - responsive layout and visual styles
- `main.js` - page rendering and interactions

To run it locally, open `index.html` in a web browser. There is no build step or package installation required.

## Deployment

The site is deployed on Vercel. Updates to the production site can be deployed from the project directory with the Vercel CLI:

```sh
vercel --prod
```
